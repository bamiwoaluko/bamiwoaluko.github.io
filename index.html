Diabetic Foot Ulcer Detection & Wagner Grade Classification
Undergraduate Dissertation · 2026

A two-stage deep learning pipeline that detects diabetic foot ulcers and classifies their severity — built with an explicit focus on reducing bias across skin tones, a gap in most clinical imaging models.

2-stage
YOLOv8 detection → ResNet50 classification
~19.9k
images across Wagner Grades 1–4
4
datasets combined & cleaned

Detection. A YOLOv8 model trained on a Roboflow foot-ulcer dataset localizes the wound region in an input image.

Classification. A ResNet50 model, trained on a combined Kaggle + SIKAD dataset, assigns a Wagner severity grade to the detected region.

Bias mitigation. Used CIELAB-based preprocessing and synthetic skin-darkening augmentation to run a dedicated ablation study on how the model's accuracy holds up across skin tones — reframed mid-project from a confirmatory check into a genuine investigative study once early results raised real questions.

Explainability. Grad-CAM++ visualizations show which regions of an image drove each classification, and the full pipeline is wrapped in a Streamlit app for interactive use.

Data integrity. Partway through, discovered rotation-invariant near-duplicate images leaking across train/test splits — rebuilt the dataset split to be cluster-safe and retrained both models on the corrected data.
